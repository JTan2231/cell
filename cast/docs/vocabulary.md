# Cast vocabulary

- **Company:** a discovered employer candidate or an independently identified
  ATS tenant. A search result alone does not verify employer identity. New means
  first observed by Cast, not necessarily newly founded.
- **Job:** one observed posting with source identity and extracted facts. It is
  not a recommendation, application or hiring outcome.
- **Source:** an observed careers collection endpoint tied to a company.
- **Observation:** source-attributed information retained at a known time.
- **Coverage:** what a query or source collection actually examined, including
  explicit partial, failed and deferred work.
- **Freshness:** age of successful evidence, distinct from the latest attempt.
- **Local budget:** Cast's conservative admission counter, distinct from a
  provider's billing or available balance.
- **Snapshot:** one consistent current discovery view with stable identities,
  revisions, evidence and coverage for downstream readers.
