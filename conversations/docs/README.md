The product-owned [Chancery provider](../chancery/provider.json) indexes the
history-exploration and development promises. Discover semantically with
`chancery list` and `chancery show`; after selecting an exact entry, run
`chancery resolve <ENTRY_ID>` to assemble its provider scope, normalized
boundary claims, documentation dependency closure, exact basis, and explicit
gaps. Documentary resolution remains separate from App Server readiness,
authorization, and successful retrieval.
