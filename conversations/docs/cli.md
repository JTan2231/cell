# CLI

Read the authoritative [history feature](../chancery/manuals/history-explore.md)
with `chancery show conversations.history.explore`. Read
[runtime configuration and diagnostics](../chancery/manuals/runtime.md)
with `chancery show conversations.runtime`. The [product overview](../chancery/overview.md)
connects the features and procedures.

## `conversations doctor [--json]`

Read [readiness and compatibility](../chancery/manuals/runtime.md#readiness-and-compatibility).

## `conversations list [FILTERS] [--title TEXT] [--limit N] [--json]`

Read [record selection](../chancery/manuals/history-explore.md#select-records-and-interpret-metadata)
and [metadata and exact summaries](../chancery/manuals/history-explore.md#list-metadata-and-resolve-an-exact-summary).

## `conversations show THREAD_ID [--turn TURN_ID] [--json]`

Read [show, search, and export](../chancery/manuals/history-explore.md#show-search-and-export-history).

## `conversations activity SESSION_OR_THREAD_ID TURN_ID [--json]`

Read [completed-turn activity](../chancery/manuals/history-explore.md#inspect-completed-turn-activity).

## `conversations search QUERY [FILTERS] [--thread-limit N] [--limit N] [--json]`

Read [search output and selection](../chancery/manuals/history-explore.md#show-search-and-export-history).

## `conversations export [FILTERS] [--limit N] [--json]`

Read [export output and selection](../chancery/manuals/history-explore.md#show-search-and-export-history).

## `conversations refresh [--json]`

Read [deliberate metadata refresh](../chancery/manuals/history-explore.md#refresh-metadata-deliberately).
