# User-owned macOS installation

Read `chancery show email.installation` for installed layout, wrapper access,
program and documentation selection, and recovery guarantees. Read
`chancery resolve email.install.operate` for supported installation, recovery,
and verification procedures with their required feature contracts.

Repository readers can open the [installation feature](../chancery/manuals/installation.md),
[installation operation](../chancery/manuals/install-operate.md), or
[product overview](../chancery/overview.md).

## Deploy

Use the published `email.install.operate` procedure for ordinary Cell delivery
or explicitly authorized manual artifact selection. Read
`chancery show ci-manager.queue.operate` for the installed queue procedure.
Read `nucleus manual` for shared deployment coordination and recovery order.

## Validate a real send

Read `chancery show email.install.operate` for the verification procedure.
Read `chancery show email.message.send` for send authority, disclosure,
Resend acceptance, and uncertain-result recovery. Real-send verification
requires separate authority from program installation.

## Supplied account settings

Read `chancery show email.account` for private settings and receiving-domain
observations. Read `chancery resolve email.account.operate` for local setup and
domain-discovery steps with the required feature contract.
