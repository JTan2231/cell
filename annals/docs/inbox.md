# Inbox documentation

Read the [inbox feature contract](../chancery/annals/manuals/inbox.md) for
admission, queue order, dispatch, attempts, controls, storage, status fields,
retry provenance, failure policy, and recovery.

Use the [inbox operating procedure](../chancery/annals/manuals/inbox-operate.md)
to inspect or operate an inbox. Read [installation](../chancery/annals/manuals/installation.md)
for platform scheduling and cutover and [decision document exchange](../chancery/annals/manuals/decision-account-exchange.md)
for the producer-only inlet.

The [Annals overview](../chancery/annals/overview.md) lists all feature contracts
and operations. Installed readers use `chancery show annals.inbox` for this
feature or `chancery resolve annals.inbox.operate` for the operation and its
required contracts.
