# Search

The [corpus-reading feature](../chancery/annals/manuals/corpus-explore.md#lexical-search)
owns lexical matching, normalization, ranking, scope, result format, cursor
rules, graph relationships, limits, and read cost.

Read the installed contract with:

```sh
chancery show annals.corpus.explore
chancery resolve annals.corpus.explore
```

Use [command navigation](cli.md#local-corpus-browsing) to find the supported
read interface. Use [interpretation](../chancery/annals/manuals/work-integrate.md)
for the liaison's revision-scoped corpus-search tool.
