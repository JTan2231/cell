# Annals Usage

Annals Usage is the companion CLI for Annals-attributed model consumption and
live account allowance. Its published feature contracts own the complete
reporting behavior.

- Read [consumption reporting](../chancery/annals-usage/manuals/consumption-inspect.md)
  for attribution, attempts and responses, token accounting, coverage, output,
  Rust interfaces, privacy, and rate-card limits.
- Read [account access and configuration](../chancery/annals-usage/manuals/execution-operate.md)
  for configuration, live allowance, diagnostics, and attended login recovery.
- Read [development](../chancery/annals-usage/manuals/develop-change.md) for
  the change procedure and [Annals installation](../chancery/annals/manuals/install-operate.md)
  for joint deployment and recovery.

Use `chancery product annals-usage` for the installed overview,
`chancery show ID` for one feature or procedure, and `chancery resolve ID`
for the required contracts and explicit gaps. Read the
[source overview](../chancery/annals-usage/overview.md) for the same product map.
