# Platter retained records

The authoritative record explanation is [materials and templates](../chancery/manuals/materials.md),
readable as `chancery show platter.materials` in the installed release.

Read [preparation](../chancery/manuals/preparation.md) for captured workflows and
eligibility, [editions](../chancery/manuals/editions.md) for independent packet
and attachment selection, and [maintenance](../chancery/manuals/maintenance.md)
for schema migration and recovery. The [overview](../chancery/overview.md)
connects these subjects. SQLite shape does not provide a supported consumer
integration surface; use [opportunity reads](../chancery/manuals/opportunity-explore.md).
