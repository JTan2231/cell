# Milieu

Milieu stores accepted companies, jobs, workplaces, and source appearances, and
exports a consistent snapshot for downstream job selection. Collection is
removed.

Downstream products own personal selection, application packets, CRM cases,
application submission, and email delivery. Milieu runs no model, Nucleus job,
computer-use tool, or downstream application workflow.

Read the installed overview with `chancery product milieu`. Read one feature with
`chancery show ID`. Read an operation and its required feature contracts with
`chancery resolve ID`. These commands read documentation. They do not establish
readiness, authorize work, or execute the documented interfaces.

## Features

| ID | Read this to understand |
| --- | --- |
| `milieu.discovery.explore` | Current record meaning, availability and evidence, stable identities, read projections, and consistent exports for consumers. |
| `milieu.state` | Private state selection, accepted current records, supported database schema, local status and readiness, source enrollment, retired controls, and state recovery. |
| `milieu.installation` | Matching program and documentation releases, selectors, frontend environment, deployment setup, and program recovery. |

## Operation

Use `milieu.install.operate` to install or recover programs, initialize state,
diagnose local readiness, or add a source. The procedure keeps prerequisites,
consequential effects, stop conditions, and verification in place. Its required
feature contracts supply the detailed explanations.

Feature pages own the behavior described here. Related references provide
navigation; required dependencies define compatible documentation closure.
Those dependencies do not transfer authority or create runtime calls.
