# Change EMT

Read EMT's AGENTS.md and service and installation contracts. Query registered
EMT Semantics when available; otherwise query Cell. Read nucleus manual before
requester, state, lifecycle or shared operational changes.

Keep two domain tables: incidents and exchanges. Keep the Nucleus reference
on the exchange. Nucleus owns execution and activity. Agents discover product
interfaces through Chancery and author their own email. Do not add an
operation ledger, product adapters or structured diagnosis without a new
user requirement.

Use provider-owned Clockwork, Email and Nucleus types and clients. Preserve
pending request identity, frozen mail, exact incident continuation, deferred
sender verification, bounded assignments and no automatic replacement job.
Diagnosis authorizes investigation; the current reply authorizes its one-off
intervention.

Source work does not authorize live jobs, account reads, messages, installation,
activation or publication. Keep private content out of source and logs.
Update owning documentation and Chancery with behavior. Update the Nucleus
operator manual for shared boundaries. Preserve unrelated work and the root
README.

Use emt/ci.sh and routine ./ci.sh when validation is authorized. Explicit
validation deferral must remain visible and must not be called a passing gate.
