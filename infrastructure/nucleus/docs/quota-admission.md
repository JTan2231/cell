# Quota admission

Read the installed feature contract through Chancery:

```sh
chancery show nucleus.quota
```

It owns quota policy, observations and freshness, configuration, admission and
execution effects, and requester recovery obligations. Use
`chancery show nucleus.execution.operate` for operating procedures, or
`chancery resolve nucleus.requester.integrate` for the complete integration
reading. This page preserves the previous documentation entry point.
