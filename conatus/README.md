# Conatus

Conatus preserves wants in their source wording and organizes subsequent
accepted decision accounts by which wants they appear to serve. It uses a
dedicated named Annals library and its stored librarian instructions.

Conatus owns capture and feed intake. Annals owns source retention,
interpretation, the concept graph, evidence, and history. A relationship is an
interpretation of service to a want; it does not establish progress, completion,
or the want's current force.
