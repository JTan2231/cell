# Conatus product and data boundaries

The [product overview](../chancery/overview.md) explains purpose, ownership and
how the features fit together. The authoritative details are
[want capture](../chancery/manuals/want-capture.md),
[want lifecycle](../chancery/manuals/want-lifecycle.md),
[library exploration](../chancery/manuals/library-explore.md),
[processing](../chancery/manuals/processing.md),
[daily email](../chancery/manuals/digest-email.md) and
[service](../chancery/manuals/service.md).

Use `chancery product conatus` for the installed overview. Read one feature with
`chancery show ID`, or use `chancery resolve ID` to include required contracts and
expose gaps. These reads do not establish readiness or authorize operations.
