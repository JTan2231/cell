# Conatus installation and activation

Read the authoritative [service feature](../chancery/manuals/service.md) for
matched releases, maintenance, immutable schedules and failure halts. Use
[Conatus operations](../chancery/manuals/update-operate.md#install-or-recover-a-release)
for installation, activation and recovery steps.

Installed readers use `chancery show conatus.service` and
`chancery resolve conatus.update.operate`. Installation, initialization,
registration and activation have separate effects. Source documentation and
catalog publication do not establish current readiness.
