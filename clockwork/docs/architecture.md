# Clockwork architecture

The product-owned [overview](../chancery/overview.md) explains purpose,
authority, and how features fit together. Clockwork publishes the complete
explanations with its release. Read the installed overview with
`chancery product clockwork`.

Read one boundary with `chancery show ID`. Resolve an operating route for its
procedure and required feature explanations. This page provides navigation;
it does not maintain a second behavior contract.
