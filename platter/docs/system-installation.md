# Platter installation

`platter-install` packages the runtime executable, retained installer and
matching Chancery provider into one verified release. Cell coordinated
maintenance owns cutover; direct installer publication and rollback are not
supported for this requester.

The complete [installation and recovery contract](../chancery/manuals/install-operate.md)
describes preparation, installed paths, prerequisite checks, durable holds,
legacy state preservation, read-only verification and recovery. Building or
validating this source does not run the installer or activate daily delivery.
